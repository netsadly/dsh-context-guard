# v0.1.1：摘要污染修复、任务循环保护与思考等级说明

2026-11-15 · 实验性预发布 · DeepSeek Harness 0.2.1-rc.5 / 本机 LM Studio / 文本会话。

## 更新内容

- **真实任务来源**：从人类来源的消息中提取根请求和近期补充，加入有界提醒；短“继续”不会把旧摘要猜测、工具输出或偶然出现的文件名升级成用户目标。
- **摘要污染校验**：摘要格式规则与任务约束分离；排除隐藏思考和重复运行通知，七个非空章节仍必须包含 Failures。增加1400字符上限及格式污染检查（加粗或换行标题同样检查），只允许一次有界修复；旧摘要缓存通过新提示身份隔离。
- **无进展保护**：最近8个工具结果中出现3次同工具、同参数、同结果，或最近实质请求/完成轮次之后出现2次无可见正文的输出耗尽时，停止该循环，输出一次明确标注的阶段答复。
- **保留工具与历史**：只有阶段答复那一次调用临时不带工具、不启用思考；后续新请求恢复正常配置，工具注册不变。原始事件继续保留，取消不伪装成完成。
- **思考等级排障说明**：记录 LM Studio 将三级降为 on 的根因、本地模型定义映射及 Off 显式关闭方式。此项为部署说明，不是插件自动修改模型或配置的功能。

## 升级方法

1. 等待任务空闲，独立备份本机 Harness 配置、插件目录和重要会话，验证备份可读。不要用备份覆盖现有会话。
2. 优先把本 Release 的源码解压到新的永久目录；或在干净源码副本中执行：

```powershell
git fetch --tags origin
git switch --detach v0.1.1
```

3. 按[中文安装教程](../README.zh-CN.md)准备 Node.js 22+、匹配宿主模块和 `@lmstudio/sdk` 1.5.0。需要安装依赖时使用 `npm ci --ignore-scripts --legacy-peer-deps`。本机已有可用 SDK 时沿用原路径。
4. 在新版源码目录重新生成本机插件包：

```powershell
node scripts/prepare-local.mjs '<Harness宿主node_modules路径>' '<SDK的dist/index.mjs路径>'
```

5. 将 Harness 插件安装位置更新到新版生成的 `private/local-plugin`，不要同时启用两份同名插件。保留本机预算覆盖项，不要用仓库模板覆盖个人配置。
6. 空闲时完全退出并重启 Harness。模型、MTP、GPU和实际窗口无需因插件升级改变。通过指令菜单调用 `context-guard status` 核对容量与预留；新会话执行实际工具任务，再检查旧会话续跑。
7. 若要修正思考等级，单独按[加载注意事项](REASONING-LMSTUDIO.zh-CN.md)验证模型定义及请求字段。安装本插件不会自动完成这一步。

16K级窗口的已验收参考组合是输出2048、摘要2048、安全余量2048、阈值0.9、保留尾部2000；仓库默认值未更改，不应照搬较大输出预留。容量变化仍由每次请求查询实际加载窗口来适配。

回退：任务空闲并退出 Harness，恢复上一版插件目录/安装位置及配置，重启核验。保留所有新旧会话记录；不以旧备份覆盖新工作。停用插件不等于撤销已经提交的历史摘要。

## 验证结果

- 默认测试47项通过、7项专用环境测试跳过；另用匹配宿主运行11项原生测试通过。
- 真实模型连续3轮污染摘要恢复通过。
- 受影响会话保留全部原始事件后，阶段答复9.7秒完成；补充原研究任务后真实搜索及答复76.3秒完成，1次搜索、1次压缩。
- 新会话 Off / Medium / High 三轮真实工具任务全部完成，分别约18.7 / 18.7 / 48.2秒，压缩0 / 1 / 2次。High出现一次额外读取后正常完成。
- 34项工具定义保持；同GGUF、MTP、16896窗口及加载参数保持。固定题生成约51–63 token/s。
- 发布前进行 Standards 与 Spec 独立 code-review。私人原始日志、配置、会话、备份和机器专用加载助手不随发布提供。

这些是不同运行路径的验收，不能称严格同任务A/B提速。上一版压缩尝试4→2的对比仍见[既有优化记录](OPTIMIZATION-2026-11-15.zh-CN.md)。

## 限制

提醒保留根请求加近期3条，每条最多700字符；阶段答复最多使用8条证据摘录，每条1100字符。因此摘要仍有损，阶段答复可能缺少资料，不能当作全部任务完成或事实核验成功。检测依据明确重复，不覆盖所有语义偏题或参数变形的重复；必要压缩仍会发生。

Low/Medium/High是现有模板的行为提示，不是硬思考token额度；Low不保证每题更短、更快。High按已测试模板映射xhigh。全新Windows安装及其他宿主/模型版本未全面验证。

本 Release 仅发布源码、合成测试与公共说明；无本地配置、会话历史、检查点、备份、生成bundle或额外Release附件，不发布npm包。
