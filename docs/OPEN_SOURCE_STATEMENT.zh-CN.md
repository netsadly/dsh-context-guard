# Context Guard 开源声明

Context Guard 面向 DeepSeek Harness 与本地 LM Studio，提供上下文预算保护、分块摘要和可续跑的会话恢复，解决长任务历史增长、实际窗口与宿主预算不匹配，以及大记录恢复被命令超时打断的问题。

**框架由作者 netsadly 设计，实际代码书写由 GPT Astra 完成。** 作者负责需求、框架方向与验收决策，GPT Astra 辅助实现、迭代与测试。这是开发分工说明，不表示相关厂商对项目提供官方认可、担保或维护承诺。

## 公开范围

仅限 `dsh-context-guard` 插件自己的源码、配置模板、安装辅助脚本、文档和合成测试。发布内容只能来自核验过的插件文件清单。

**不包括作者其他项目与仓库**，也不包括个人聊天记录、原始会话、恢复摘要、检查点、备份、运行日志、密钥、私人配置、本机路径生成的安装包、模型权重、宿主或第三方依赖的复制品。真实验收只记录必要的匿名统计和结果，不附私人原文。

## 质量与数据边界

项目采用独立的规范审查、需求审查及回归测试。测试通过不等于适配所有宿主和模型版本，摘要也不保证事实完整，用户应独立备份重要记录。恢复命令不会自动继续历史任务。

检查点是未加密的本地明文 JSON，可能含私人摘要。插件不保证宿主、备份和同步软件不会复制或上传文件；校验和只用于检测意外损坏，不提供认证或防篡改保护。重启恢复验收仅代表已记录的特定会话，不保证完整事实保留或所有会话可恢复。
