# Harness 上下文保护插件

这是私有验证版，针对 **DeepSeek Harness 0.2.1-rc.5 + LM Studio**，暂未公开发布。

插件会在模型请求前读取实际已加载窗口，结合本地分词、输出预留和安全余量判断是否需要压缩。接近阈值时将旧消息分块摘要，再合并为检查点。原始会话事件保留在原日志里。

## 使用

安装包由 `scripts/prepare-local.mjs` 生成。通过 Harness「插件 → 添加插件」安装本地目录，再启用。修改源码并重新生成后，在会话空闲时重启 Harness。

在对话输入框左下角点击 **+ → context-guard**，选中命令后输入参数：

- `status`：查看当前模型窗口、输出预留和输入估计。
- `recover`：对空闲会话进行恢复压缩，不继续执行原任务。

必须选中命令标签。直接粘贴普通文本 `/context-guard recover` 可能被当成聊天发送给模型。

恢复重要会话前，先独立备份对应的 `session.v4.jsonl.zstd` 并核对校验值。插件保留原事件，但不会自动生成独立备份。恢复成功后检查摘要，再决定是否继续工作。

## 默认安装配置

| 设置 | 数值 |
| --- | --- |
| 本地服务 | `http://127.0.0.1:1234` |
| 无有效输出上限时的回退值 | 8,192 token |
| 每次摘要最大输出 | 2,048 token |
| 安全余量 | 2,048 token |
| 触发位置 | 剩余输入预算的 80% |
| 保留最近消息的目标 | 约 2,000 token |
| 整轮分块摘要总时限 | 10 分钟 |
| 最多摘要调用次数 | 32 |

已有有效输出上限会保留；不会把上下文不足的问题处理成只允许输出 1 token。摘要请求明确关闭思考，正常聊天的推理档位不变。

## 适用范围

实测桌面手动命令约 5 分钟会被宿主取消，即使插件配置允许 10 分钟。精简摘要可以缩短耗时，但不能绕过宿主时限；超长记录或较慢模型仍可能恢复失败，失败时不会提交不完整摘要。

摘要目前使用精简英文，要求保留原始路径和标识符；这不改变日常对话语言。180 词／1400 字符是提示目标，实际硬上限由 token、调用次数和超时控制。

- 支持文本会话、文本工具结果。图片、音频和文件内容暂不支持，遇到它们会停止请求。
- 分词计数包含余量，但不是模型最终聊天模板的精确长度。
- “输出 token 达到上限”也可能是单次回答或思考太长，压缩上下文不能消除这类正常的输出限制。
- 本地长记录需要多个摘要请求，可能用时数分钟。失败或超时不会把不完整摘要提交为检查点。
- 摘要有损，结构校验不能保证每个事实正确。关键事实仍以原记录为准。
- 替换的是全局压缩服务，其他模型提供方暂不适用。切换到其他提供方前应停用本插件。
- SDK 分词接口不支持取消底层 RPC；插件限制最多一个未完成请求，避免反复重试堆积。出现一直不结束的分词连接时，重启插件后再试。

## 代码审查与公开发布

项目默认按 **代码规范** 和 **需求符合性** 两条独立路径审查，并运行回归测试。普通使用插件不会自动调用云端代码审查模型。

GitHub 仅保存源码、说明和合成测试；本地安装入口、日志、聊天记录、恢复摘要和备份均排除上传。公开发布、开源许可证及适配更多版本需要另行决定。
